# Charging Adviser — preview
Open index.html directly or run `python3 -m http.server 8000` in this directory. For serverless form testing use `vercel dev`; deploy the directory as a static Vercel project with Node serverless functions. No dependencies required. Preview is intentionally noindex and form disabled.

## Launch checklist
- Confirm brand, founder names/team composition, prior HIVERY relationships and permission to publish. No logos/customer claims included. Edit FOUNDER_COPY in config.js and review public text. Replace brand strings and mark in build.py (regenerate HTML) and CSS as needed. TAX_NOTE controls optional tax wording. Confirm legal entity, contact, tax, hosting, processor, analytics, AI provider and retention; rewrite privacy.html with confirmed details before enabling application.
- Configure server-only LEAD_WEBHOOK_URL and LEAD_WEBHOOK_TOKEN for a trusted processor that returns 2xx only after durable storage; set LAUNCH_APPROVED=true after review. Set APPLICATION_ENABLED=true in config.js only then. Current basic IP rate limiting is per warm serverless instance; use shared rate limiting or provider protection for production. Test spam honeypot, invalid data, failure and successful webhook persistence with synthetic data; ensure conversion only fires on success. No live lead endpoint supplied or tested.
- Analytics: assign ANALYTICS_EVENT to a provider adapter; custom charging:analytics events contain only event names and demo index, no form values. Approved UTMs are sent with application. Review consent requirements before adding analytics. Primary metric qualified applications; track operator fit, exportability, job, discovery and paid acceptance in lead system.
- Set canonical and OG URL in HTML after production domain confirmation; create sitemap.xml using actual domain and update robots.txt to allow public landing page; remove noindex from approved production landing and privacy pages only. Keep previews and thank-you noindex. Add verified Organization/Service structured data only after identity confirmation. Optional booking link is not rendered until implemented with verified URL. Do not launch before completing these steps.
- Sample examples are deterministic fictional data, no AI API. Report opens or downloads as HTML. No control, live data or customer claims. Test keyboard tabs, mobile layout, reduced motion and browser compatibility before release. Build.py regenerates initial HTML; edit its source to preserve changes. CSS and JS are separate editable files.
